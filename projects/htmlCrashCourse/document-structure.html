Document structure

Every HTML document has the same skeleton:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Page</title>
</head>
<body>
    <!-- visible content goes here -->
</body>
</html>

What each piece actually does

  • <!DOCTYPE html> tells the browser to render the page in standards mode, using the current HTML rules, rather than an old legacy compatibility mode. It has to be the very first line.
  • <html lang="en"> is the root element. The lang attribute isn't decorative — screen readers use it to choose pronunciation rules, and browsers use it for things like offering translation.
  • <head> holds metadata about the page — nothing in it is rendered directly as visible page content.
  • <meta charset="UTF-8"> tells the browser how to interpret the bytes of the file as text. Without it, special characters (accents, curly quotes, emoji) can render as garbage.
  • <title> is what shows in the browser tab and in search results — it's the one piece of <head> content a user actually sees, just not inside the page itself.
  • <body> holds everything that actually renders on the page.

Elements, tags, and attributes — the vocabulary

An element is a piece of content plus its meaning — "this is a paragraph." A tag is the actual <p>/</p> markup that delimits it. Most elements have an opening and closing tag; a few (like <meta> and <img>) are "void" elements with no closing tag or content, because they don't wrap anything.

An attribute is extra information attached to the opening tag, written as name="value" — lang="en" and charset="UTF-8" above are both attributes.

Apply it

Create profile.html with just this skeleton. Set the <title> to your name. Leave <body> empty for now — you'll fill it in over the next several chapters. Open the file directly in a browser (double-click it, or drag it into a browser window) and confirm the tab shows your name.
