Starter file structure

If you worked through each "Apply it" section as you went, you already have this file built piece by piece. This chapter is here for two reasons: as a reference scaffold if you'd rather start over cleanly, and as a folder layout for the image you added earlier. 

profile-page/
├── profile.html
└── images/
    └── profile.jpg   (or whatever you used)
