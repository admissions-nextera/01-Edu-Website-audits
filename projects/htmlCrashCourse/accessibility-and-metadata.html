Accessibility and metadata

Most of this guide has been pointing at accessibility along the way rather than saving it for the end, because in HTML the two aren't really separable — correct semantic markup is most of what accessibility means at this layer. This chapter collects the pieces and adds a few that didn't fit naturally earlier.

Quick checklist against what you've already built

  • Every <img> has a meaningful alt — not the filename, not "image," an actual description of what it shows.
  • Every <input> has an associated <label>.
  • Headings nest in order with exactly one <h1>.
  • Link text describes the destination, not "click here."
  • <html lang="en"> is set (or whatever language you're actually writing in).

Metadata you haven't added yet

<meta name="description" content="Personal profile page for Jane Doe, backend developer.">
<link rel="icon" href="favicon.ico">
  • <meta name="description"> is commonly what search engines show as the snippet under your page's title in results. It's not visible on the page itself — it lives entirely in <head>.
  • <link rel="icon"> sets the small icon shown in the browser tab (the favicon). Not required for the page to "work," but its absence is a common tell of an unfinished page.

tabindex and focus order (know it exists, don't overuse it)

By default, a keyboard user tabs through interactive elements (links, inputs, buttons) in the order they appear in the HTML — another reason source order matters, independent of anything visual. tabindex="0" can insert a normally non-interactive element into that tab order; tabindex="-1" removes something from it while still allowing it to be focused programmatically. Positive tabindex values (tabindex="1", etc.) let you override the natural order entirely, and are almost always a mistake — they're a common source of confusing, inconsistent keyboard navigation. For this project, you shouldn't need tabindex at all; it's worth knowing it exists so you recognize it (and avoid misusing it) later.

Apply it

Go back through your entire profile.html against the checklist above and fix anything that doesn't hold up — this is a real audit of your own file, not a new section to add. Then add a <meta name="description"> to your <head> summarizing the page in one sentence.
