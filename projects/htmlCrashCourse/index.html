HTML Crash Course + Project: Personal Profile Page

This guide teaches HTML by having you build something real as you go. Each chapter covers one piece of HTML and then has you apply it immediately to a single, growing project: a personal developer profile page. By the last chapter you'll have a complete, semantic HTML page and a working understanding of every tag in it — not just a page you copied.

No CSS, no JavaScript. Structure only, on purpose — that's the whole point of learning HTML on its own before anything else gets layered on top.
