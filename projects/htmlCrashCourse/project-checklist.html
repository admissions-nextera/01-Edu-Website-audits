Final project checklist

If you followed the "Apply it" section of every chapter, this is mostly a verification pass, not new work. Go through profile.html and confirm every item.

Structure

  • <!DOCTYPE html>, <html lang="...">, <meta charset="UTF-8">, and a real <title> are all present.
  • <meta name="description"> is present and accurate.
  • The page is wrapped in <header> / <main> / <footer>, with <nav> inside the header linking to each section.
  • Exactly one <h1>; every other heading nests without skipping a level.

Content sections

  • An About section with a bio paragraph, including at least one <strong> used meaningfully.
  • A Skills section using a list (<ul>, with at least one nested sublist, or a <dl>).
  • At least one profile or project image with a real, descriptive alt, loaded via a relative path.
  • A set of external links (GitHub, etc.) each with descriptive link text.
  • An Experience/Education section using a properly structured <table> with <thead>/<tbody>.
  • A Contact section with a form: labeled name field, labeled required email field, labeled message textarea, and a submit button.

Accessibility

  • Every <img> has a meaningful alt.
  • Every <input>/<textarea> has an associated <label> via matching for/id.
  • No link text says "click here" or "here."

Sanity checks

  • Every opening tag has a matching closing tag (except void elements: <img>, <br>, <hr>, <input>, <meta>, <link>).
  • Nav links (#about, #skills, etc.) each actually land on a section with a matching id.
  • The page opens correctly in a browser with no visibly broken structure — even without CSS, a well-structured page reads top to bottom in a sensible order.
