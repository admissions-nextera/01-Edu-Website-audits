main.go — this one is given in full. Wiring up routes is boilerplate, not the point of the exercise. 

package main

import (
    "log"
    "net/http"
)

func main() {
    h := NewHistory("home")

    mux := http.NewServeMux()
    mux.HandleFunc("POST /visit", visitHandler(h))
    mux.HandleFunc("POST /back", backHandler(h))
    mux.HandleFunc("POST /forward", forwardHandler(h))
    mux.HandleFunc("GET /current", currentHandler(h))
    mux.HandleFunc("GET /history", historyHandler(h))

    log.Println("listening on :8080")
    log.Fatal(http.ListenAndServe(":8080", mux))
}

Notice the handler functions are written as functions that return an http.HandlerFunc, closing over h. This is how you hand a handler access to shared state without using a package-level global variable — worth noticing now, since it's a pattern you'll see constantly in real Go HTTP code.
