Project: Browser History Simulator

This project combines the two things covered in the last session: stacks, and building an HTTP server in Go. You'll build a small service that simulates how a browser's Back/Forward buttons work, using two stacks underneath, and expose it over HTTP so it behaves like a real (tiny) web service.

This guide is meant to be worked through on your own. It doesn't hand you finished code for the core logic — it gives you the spec, a starter file structure, and guided steps with hints. Where full code is given (the starter scaffold, the wiring), it's the boilerplate around your logic, not the logic itself.
